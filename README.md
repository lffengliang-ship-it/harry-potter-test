# 霍格沃茨学院分院测试

哈利波特世界观下的性格测试 H5 页面。

## 功能
- 8 道情境选择题
- 四大学院分院
- 角色匹配 + 剧照展示
- 角色特点、擅长魔法、名场面故事
- 进度条、移动端适配、结果分享
- SEO / 社交分享基础信息

## 本次优化方向
- 首屏增加更强的霍格沃茨氛围和分享描述
- 答题页增加进度条和更清晰的选项交互
- 结果页按钮区适配手机宽度
- 修复分享结果时可能重新随机角色的问题

## PR2 迭代方向
- 首页升级为霍格沃茨入学通知书视觉
- 8 道题重写为魔法世界故事场景题
- 结果页升级为分院帽判词、角色命运卡和专属咒语
- 专属咒语增加中文读音辅助，方便用户分享和二创
- 保持纯静态页面，不引入后端和构建流程

## 本地预览
```bash
# 方式1：直接打开
open index.html

# 方式2：本地服务器
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 部署到 GitHub Pages
1. 创建 GitHub 仓库 `harry-potter-test`
2. 推送代码到 `main` 分支
3. Settings → Pages → Source: Deploy from a branch → main → / (root)
4. 访问 `https://<你的用户名>.github.io/harry-potter-test/`

## 替换角色图片
1. 准备角色图片，放入 `assets/characters/`
2. 修改 `config.js` 中的图片路径
3. 无需修改业务代码
